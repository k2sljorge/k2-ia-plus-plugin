# K2 IA Plus para Sage 200

Plugin de Claude para K2 IA Plus, el asistente de IA de K2 Software Leader para Sage 200.

## Qué hace

- Conecta Claude con el servidor MCP de K2 en `https://iaplus.k2sl.com/mcp`.
- Tus preguntas, las consultas que escribe Claude y sus resultados viajan entre Claude y ese servidor. Las consultas solo leen los datos de tu empresa.
- Puede guardar informes en K2 BI, siempre después de que lo confirmes.
- Hace falta una cuenta de K2 contratada. Al conectar, entras con el usuario de tu empresa en su web de K2, con doble verificación o con Microsoft o Google.
- Las skills solo explican cómo usar el conector. No ejecutan código en tu equipo ni envían datos a ningún otro sitio.

# K2 IA Plus for Sage 200 (English)

Claude plugin for K2 IA Plus, the AI assistant for Sage 200 by K2 Software Leader.

## What it does

- Connects Claude to K2's MCP server at `https://iaplus.k2sl.com/mcp`.
- Your questions, the queries Claude writes and their results travel between Claude and that server. Queries are read-only over your company's data.
- It can save reports to K2 BI, always after you confirm.
- It requires a subscribed K2 account. When connecting, you sign in with your company user on its K2 web, with two-step verification or with Microsoft or Google.
- The skills only explain how to use the connector. They run no code on your machine and send no data anywhere else.
