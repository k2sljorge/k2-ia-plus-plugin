# K2 IA Plus para Sage 200

Plugin de Claude para el Asistente plus de IA de K2 para Sage 200, de K2 Software Leader.

- Conecta Claude con `https://iaplus.k2sl.com/mcp`. Al conectar, entras con el usuario de tu empresa.
- Consultas en lenguaje natural sobre los datos de tu empresa. Las consultas solo leen.
- Guardar informes en K2 BI, siempre con tu confirmación.
